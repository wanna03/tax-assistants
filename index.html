ต้นแบบนี้เป็นระบบ Rule-Based ไม่ได้เชื่อมต่อ AI API และไม่ได้ตรวจสอบการแก้ไขกฎหมายแบบเรียลไทม์ รายการอัตราที่แสดงเป็นเพียงแนวทางสำหรับกรณีทั่วไปตามเงื่อนไขที่ระบุ ไม่ครอบคลุมธุรกรรมข้ามประเทศ ภาษีเฉพาะธุรกิจ เงินได้ตามมาตรา 40(1) ทุกกรณี หรือข้อยกเว้นเฉพาะทั้งหมด

  • คำสั่งกรมสรรพากรที่ ท.ป.4/2528 และฉบับแก้ไข
  • แนวทางการหักภาษี ณ ที่จ่ายตามมาตรา 3 เตรส
  • คู่มือกรมสรรพากร: ผู้มีหน้าที่หักและแบบนำส่ง
